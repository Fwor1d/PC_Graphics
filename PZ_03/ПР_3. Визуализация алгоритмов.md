# Практическая работа № 3

## Визуализация алгоритмов сортировки и бинарного поиска

Необходимо разработать интерактивное приложение на **Python + PyGame**, позволяющее пошагово наблюдать работу трёх алгоритмов:

1. пузырьковой сортировки;
2. сортировки выбором;
3. бинарного поиска.

Приложение должно показывать не только конечный результат, но и последовательность промежуточных состояний алгоритма.

---

## Задание 1. Создание приложения

Создать окно PyGame размером не менее:

```text
1100 × 700
```

В окне должны присутствовать:

- область визуализации массива;
- название выбранного алгоритма;
- текущее состояние выполнения;
- панель статистики;
- краткая подсказка по управлению.

Приложение должно корректно завершаться через `Esc` и кнопку закрытия окна.

---

## Задание 2. Исходный массив

Создавать массив случайных целых чисел.

Рекомендуемые параметры:

```text
количество элементов: 20–50
значения: 10–100
```

Клавиша `R` должна генерировать новый массив.

> Новый массив не должен создаваться во время активного выполнения алгоритма без предварительного сброса состояния.

---

## Задание 3. Графическое представление массива

Каждый элемент представить вертикальным столбцом.

Требования:

- высота пропорциональна значению;
- столбцы равномерно распределены по рабочей области;
- визуализация корректно работает при различном количестве элементов;
- значения не должны выходить за границы окна.

Для небольшого массива допускается вывод числового значения над\под\поверх столбца.

---

## Задание 4. Единая система визуальных состояний

Использовать разные визуальные состояния минимум для:

```text
обычный элемент
сравниваемый элемент
элемент, участвующий в обмене
выбранный минимум
отсортированный элемент
активный диапазон бинарного поиска
mid
найденный элемент
исключённый элемент
```

В интерфейсе должна присутствовать небольшая легенда цветов.

Цвета должны использоваться последовательно во всех алгоритмах.

---

## Задание 5. Пузырьковая сортировка

Реализовать Bubble Sort.

Визуализация должна показывать:

1. два сравниваемых соседних элемента;
2. факт обмена элементов;
3. элементы, которые уже заняли окончательную позицию;
4. завершение очередного прохода.

Алгоритм должен использовать оптимизацию раннего завершения:

```text
если во время прохода не произошло ни одного обмена,
сортировка завершается досрочно
```

## Задание 7. Сортировка выбором

Реализовать Selection Sort.

На экране должны визуально различаться:

1. начало неотсортированной области;
2. текущий проверяемый элемент;
3. индекс минимального найденного элемента;
4. обмен минимума с началом рабочей области;
5. отсортированная часть массива.

---

## Задание 9. Пошаговое выполнение через генераторы

Bubble Sort и Selection Sort необходимо реализовать как пошаговые алгоритмы.

Рекомендуемый интерфейс:

```python
def bubble_sort_steps(values):
    yield step


def selection_sort_steps(values):
    yield step
```

Каждый `yield` должен возвращать информацию, необходимую визуализатору.

Не допускается реализация, при которой алгоритм сначала выполняется полностью, а затем проигрывается заранее сохранённый набор кадров.

Реализовать:

```text

R     — новый массив
```

Пауза не должна останавливать event loop PyGame.

## Задание 12. Бинарный поиск

Добавить третий режим:

```text
Binary Search
```

Бинарный поиск выполняется только по отсортированному массиву.

Перед запуском поиска приложение должно гарантировать упорядоченность данных.

Допускаются два варианта:

1. использовать массив, полученный после визуализированной сортировки;
2. создать отдельную отсортированную копию массива для режима поиска.

---

## Задание 13. Выбор искомого значения

Пользователь должен иметь возможность задать `target`.

Допустимые варианты интерфейса:

- ввод числа с клавиатуры;
- выбор одного из элементов мышью;
- генерация случайного значения отдельной клавишей.

Необходимо обеспечить возможность проверить два случая:

```text
target существует в массиве
target отсутствует в массиве
```
