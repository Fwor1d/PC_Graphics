# Практическая работа №3. Визуализация алгоритмов

Приложение на Python и PyGame: пузырьковая сортировка, сортировка выбором и бинарный поиск.

## Запуск

```bash
pip install pygame
python main.py
```

## Управление

- `1` - Bubble Sort
- `2` - Selection Sort
- `3` - Binary Search (по отсортированной копии массива)
- `Space` - запуск / пауза
- `N` - один шаг
- `R` - сброс и новый случайный массив
- `T` - ввод искомого значения в Binary Search
- `0-9` - цифры искомого значения
- `Backspace` - удалить цифру
- `Enter` - применить значение
- `Esc` - выход

Для проверки отсутствующего элемента в Binary Search нажмите `T` и введите `999`.
