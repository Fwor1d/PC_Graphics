# PC_Graphics

Репозиторий с практическими работами по дисциплине **«Компьютерная графика»**. Каждая работа находится в отдельной папке с кодом, ресурсами и инструкцией.

## Содержание

| Практическая работа | Ссылка | Описание |
|---|---|---|
| ПЗ №1 | [Обработка изображений](./PZ_01/) | Каналы RGB, яркость, масштабирование, поворот и оттенки серого с Pillow и NumPy |
| ПЗ №2 | [Симулятор пекарни](./PZ_02/) | Перемещение клиента и оформление заказа в PyGame |
| ПЗ №3 | [Визуализация алгоритмов](./PZ_03/) | Пузырьковая сортировка, сортировка выбором и бинарный поиск |
| ПЗ №4 | [Поиск пути](./PZ_04/) | Визуализация BFS, Dijkstra и A* на сетке |
| ПЗ №5 | [Affine Transform Studio](./PZ_05/) | Аффинные преобразования, композиция матриц, pivot и выделение по силуэту |

## Организация репозитория

```text
PC_Graphics/
├── PZ_01/   # обработка изображений и результаты
├── PZ_02/   # симулятор пекарни
├── PZ_03/   # визуализация алгоритмов
├── PZ_04/   # поиск пути и тесты
├── PZ_05/   # редактор аффинных преобразований и тесты
├── temp/    # ранее сохранённые материалы
├── .gitignore
└── README.md
```

## Как открыть и запустить работу в PyCharm

1. Откройте существующую папку `PC_Graphics` в PyCharm через **File → Open**.
2. В настройках Python Interpreter выберите окружение проекта `.venv` или создайте виртуальное окружение.
3. Установите зависимости, перечисленные в README выбранной работы. Для ПЗ №4 можно установить их из `PZ_04/requirements.txt`.
4. Откройте `main.py` нужной работы и нажмите **Run**. Для ПЗ №1 в консоли можно ввести угол поворота или нажать Enter. Подробности и управление приведены в README работы.
