# PC_Graphics

Репозиторий с практическими работами по дисциплине **«Компьютерная графика»**.
Каждая работа размещается в отдельной папке вместе с исходным кодом, необходимыми ресурсами, инструкциями и (при наличии) тестами.

|---|---|---|
| ПЗ №1 | [Открыть `PZ_01`](./PZ_01/) | Исходные файлы практической работы №1 |
| ПЗ №2 | [Открыть `Pz_02`](./Pz_02/) | Исходные файлы практической работы №2 |
| ПЗ №3 | [Открыть `Pz_03`](./Pz_03/) | Исходные файлы практической работы №3 |
| ПЗ №4 | [Открыть `PZ_04`](./PZ_04/) | Визуализация BFS, Dijkstra и A* в PyGame |



## Организация репозитория

```text
PC_Graphics/
├── PZ_01/                  # практическая работа №1
├── Pz_02/                  # практическая работа №2
├── Pz_03/                  # практическая работа №3
├── PZ_04/                  # практическая работа №4
├── .gitignore
└── README.md
```

В каждой папке ПЗ хранятся только файлы, относящиеся к соответствующей работе. Скриншоты выполненных заданий можно помещать в подпапку `screenshots/`.

## Как открыть и запустить работу

1. На GitHub нажмите **Code > Download ZIP**, чтобы получить все работы, или скопируйте HTTPS-ссылку из **Code** и выполните `git clone <ссылка>`.
2. Откройте папку `PC_Graphics` в **PyCharm**.
3. Перейдите в папку нужной практической работы.
4. Если в папке есть `README.md`, используйте его инструкцию. При наличии `requirements.txt` установите зависимости в активное виртуальное окружение.
